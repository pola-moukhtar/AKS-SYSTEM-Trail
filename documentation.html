نظرة عامة على المشروع


هذا المشروع هو موقع مجموعة أفا كيرلس الكشفية (AKS)، وهو نظام لإدارة المجموعة يساعد في إدارة الكشافة، وحسابات القادة، والطلائع، والحضور، ومهام المتابعة، والسجلات، والطلبات، والتقارير.

النظام مبني باستخدام صفحات ويب ثابتة تتصل بـ Supabase كخدمة لقاعدة البيانات الخلفية. تتم إدارة تسجيل الدخول والصلاحيات والبحث والتعديل والتصفية والرسوم البيانية وتصدير PDF وExcel وعمليات قاعدة البيانات من خلال JavaScript في الواجهة الأمامية واستعلامات Supabase.

صلاحيات المستخدمين


المسؤول الرئيسي Master

ده أعلى مستوى صلاحيات في السيستم، وبيقدر يدخل على كل الصفحات ويشوف كل البيانات. يقدر يوافق على طلبات القادة والكشافة، ويدير حسابات القادة، ويشوف كل القطاعات， ويتحكم في كل العمليات الإدارية في السيستم.

القائد العام

عنده صلاحيات واسعة على مستوى المجموعة كلها. يقدر يدخل على لوحات الإدارة， ويوافق على طلبات القادة والكشافة، ويتابع ويدير العمليات العامة الخاصة بالمجموعة.

قائد القطاع

بيقدر يشوف القطاع أو المرحلة المسؤول عنها بس. يقدر يتابع ويدير بيانات الكشافة والطلائع الخاصة بقطاعه، وكمان يراجع الطلبات الخاصة بالقطاع.

قائد الفرقة

بيقدر يشوف الكشافة والطلائع اللي تابعين للفرقة المسؤول عنها. يقدر يعمل ويتابع مهام المتابعة الخاصة بيه، وفي الحالات اللي مش مسموح له فيها يعدّل البيانات بشكل مباشر، بيبعت طلب تعديل للمسؤولين الأعلى عشان يتم مراجعته واعتماده.

عشيرة

عنده صلاحية دخول محدودة. يقدر يسجل الدخول للسيستم، لكن الوصول لبيانات الكشافة والعمليات الأساسية بيكون مقفول أو محدود حسب الصلاحيات المسموح بيها.

جداول البيانات الأساسية


  • leaders: حسابات تسجيل الدخول وتعريف الصلاحيات.
  • scouts: بيانات وملفات الكشافة.
  • attendance: سجلات الحضور والتقييم.
  • patrols: أسماء الطلائع وعلاقتها بالفرقة والقطاع.
  • scout_requests: طلبات تعديل أو حذف بيانات الكشافة.
  • follow_up_tasks: مهام المتابعة مع بيانات القائد المسؤول عنها.

طريقة استخدام الموقع


  1. افتح صفحة تسجيل الدخول من index.html.
  2. سجّل الدخول باستخدام اسم المستخدم وكلمة المرور الخاصة بالقائد من جدول `leaders`.
  3. بعد تسجيل الدخول بنجاح يتم حفظ الجلسة في المتصفح.
  4. استخدم الكروت الموجودة في الصفحة الرئيسية للانتقال إلى أقسام النظام المختلفة.
  5. استخدم صفحة `dashboard.html` للبحث والتصفية ومراجعة وإدارة بيانات الكشافة.
  6. الصلاحيات الأعلى تقوم بمراجعة واعتماد الطلبات التي ينشئها المستخدمون أصحاب الصلاحيات الأقل.

ملاحظات الأمان والتشغيل


الإصدار الحالي يحفظ جلسة القائد الذي قام بتسجيل الدخول داخل المتصفح باستخدام `localStorage`، ويتم تنفيذ معظم عمليات قاعدة البيانات من خلال استدعاءات Supabase في الواجهة الأمامية. في حالة استخدام النظام بشكل إنتاجي، يُفضّل نقل عمليات الكتابة خلف API آمن وتفعيل سياسات Row Level Security في Supabase.
